## Defect Handling

When a test fails:
1. Investigate root cause (don't mask)
2. If genuine critical bug (financial/data/security):
   - Add regression test FIRST (proving the bug)
   - Fix application code
   - Verify regression test now passes
   - Re-run all related tests
   - Document in defect register
3. If non-critical:
   - Document with severity LOW/MEDIUM
   - Do not fix unless trivial
4. If test defect (wrong assumption):
   - Fix the test, document why
