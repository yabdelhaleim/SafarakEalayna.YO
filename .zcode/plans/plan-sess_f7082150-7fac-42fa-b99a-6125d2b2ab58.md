### True concurrency (FM-47..50):

```php
$spawnConcurrentWorkers = function (string $inlineScript, int $workers): array {
    $procs = [];
    $startScript = base_path('storage/app/fm_concurrent_worker.php');  // temporary file
    file_put_contents($startScript, $inlineScript);

    for ($i = 0; $i < $workers; $i++) {
        $cmd = sprintf('php artisan tinker --execute="require \'%s\';" 2>&1', $startScript);
        $procs[$i] = proc_open($cmd, [1 => ['pipe', 'w'], 2 => ['pipe', 'w']], $pipes[$i]);
    }

    // Wait + collect
    $results = [];
    foreach ($procs as $i => $proc) {
        $results[$i] = stream_get_contents($pipes[$i][1]);
        fclose($pipes[$i][1]);
        fclose($pipes[$i][2]);
        proc_close($proc);
    }
    unlink($startScript);
    return $results;
};
```

## Risks & Mitigations

| Risk | Mitigation |
|---|---|
| SQLite concurrency weaker than MySQL | Use SQLite for baseline + scenarios; flag FM-47..50 as PARTIAL if infra fails |
| Some mutations ARE allowed in Eloquent (e.g., direct `update`) → tests show pass but it's a real defect | Record as MEDIUM defect (no financial impact but bypasses guard) |
| Currency rate precision differs between SQLite/MySQL | Run FX checks with `bccomp` for KWD precision, not `==` |
| `php artisan tinker --execute` eval scope issues | Use closures (not global functions) — same pattern as existing E2E |
| `proc_open` blocked on Windows | Use `start /B` or fall back to sequential — document as PARTIAL if needed |
| Pre-existing test data (Cashbox seeded at 100k) interferes | Pre-cleanup phase deletes any PHASE10-* / FM-* markers before run |
