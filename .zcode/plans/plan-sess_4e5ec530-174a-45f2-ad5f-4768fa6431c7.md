# خطة محدّثة: اسكربت شامل لكل عمليات الطيران (E2E Audit على MySQL منفصلة)

بناءً على التوضيح الأخير: سنستخدم داتا بي MySQL منفصلة اسمها `safarak_flight_audit` على نفس سيرفر الـ staging، معزولة تماماً عن الـ production DB. هذا آمن 100%.

## 1) الاستراتيجية

**لا نلمس الـ staging DB الأصلية ولا البرودكشن إطلاقاً.**

الفصل يكون عبر:
- إنشاء DB جديدة: `safarak_flight_audit` (utf8mb4 / utf8mb4_unicode_ci / نفس الـ charset)
- استخدام نفس MySQL user (أو user منفصل بصلاحيات محدودة)
- `phpunit.audit.xml` يشير لهذه الـ DB عبر `DB_DATABASE=safarak_flight_audit`
- migrations تشتغل على الـ DB الجديدة فقط (`php artisan migrate --database=mysql_audit --force`)
- بعد انتهاء الاختبار، الـ DB تبقى موجودة للتفتيش اليدوي، أو تُحذف بأمر واحد

## 6) بنية الاختبار — `FlightFullOperationsAuditTest.php`

```php
<?php

namespace Tests\Feature\Flight;

use Tests\TestCase;
use Illuminate\Foundation\Testing\DatabaseTransactions;  // rollback آمن
use Illuminate\Support\Facades\DB;
// ... imports

class FlightFullOperationsAuditTest extends TestCase
{
    use DatabaseTransactions;  // ← بدل RefreshDatabase

    private FlightAuditScenarioBuilder $builder;
    private AuditReporter $reporter;

    protected function setUp(): void
    {
        parent::setUp();
        $this->reporter = new AuditReporter();
        $this->reporter->banner('FLIGHT FULL OPERATIONS AUDIT — MySQL: ' . DB::connection()->getDatabaseName());
        $this->builder = new FlightAuditScenarioBuilder($this->reporter);
        $this->builder->setup();
    }

    public function test_channel_currency_matrix(): void { /* 15 سيناريو */ }
    public function test_payment_cross_currency(): void { /* 5 سيناريو */ }
    public function test_cancellation_scenarios(): void { /* 4 سيناريو */ }
    public function test_refund_request_flows(): void { /* 3 سيناريو */ }
    public function test_deletion_scenarios(): void { /* 4 سيناريو */ }
    public function test_multi_leg_bookings(): void { /* 2 سيناريو */ }
    public function test_final_reconciliation(): void { /* invariants نهائية */ }

    protected function tearDown(): void
    {
        $this->reporter->summary();
        parent::tearDown();
    }
}
```

**لماذا `DatabaseTransactions` وليس `RefreshDatabase`؟**
- `RefreshDatabase` يعمل TRUNCATE — كارثي على DB حقيقية
- `DatabaseTransactions` يلف كل شيء في transaction ويلفّيه ROLLBACK في النهاية
- البيانات تُمسح تلقائياً لكن الـ schema يبقى

## 7) مصفوفة السيناريوهات (~33 سيناريو)

### A. Channel × Currency Matrix (15 سيناريو)
- SIGN × {EGP, USD, SAR, EUR, KWD}
- SYSTEM × {EGP, USD, SAR, EUR, KWD}
- GROUP × {EGP, USD, SAR, EUR, KWD}

كل سيناريو: create + full pay → التحقق من AR, carrier/system/group balance, income, segments, tickets, status=CONFIRMED

### B. Cross-Currency Payment (5 سيناريو)
- EGP booking + EGP pay
- EGP booking + USD pay
- USD booking + EGP pay
- USD booking + USD pay (same-ccy)
- KWD booking + EGP pay

### C. Cancellation (4 سيناريو)
- Cancel CONFIRMED + full refund
- Cancel CONFIRMED + penalty only (no refund)
- Cancel PENDING (no payment)
- Cancel PARTIALLY_REFUNDED

### D. RefundRequest (3 سيناريو)
- Partial refund → agency treasury
- Full refund → agency treasury
- Full refund → airline credit voucher

### E. Deletion (4 سيناريو)
- Delete PENDING booking
- Delete CONFIRMED (direct, full payment)
- Delete REFUNDED (after cancel)
- Delete CANCELLED (after penalty-only cancel)

### F. Multi-leg (2 سيناريو)
- One-way booking
- Round-trip (2 segments)

### G. Final Reconciliation
- INV-A: account.balance == SUM(credit) − SUM(debit)
- INV-B: transaction.debit == transaction.credit
- INV-C: FlightCarrier.balance == Σ(transactions)
- INV-D: لا orphan account_entries
- INV-E: لا orphan transactions
- INV-F: pending_sales_receivable == −selling_price (per booking)
- INV-G: P&L totalRevenues == 0
- INV-H: P&L totalCogs == 0
- INV-I: P&L netProfit == 0
- INV-J: prepaid GL == Σ(carrier + system + group balances)

## 9) الـ Upload + Run Script

### `scripts/audit_flight_full.sh`
```bash
#!/usr/bin/env bash
set -euo pipefail

: "${STAGING_HOST:?Set STAGING_HOST (e.g. staging.safarakealayna.com)}"
: "${STAGING_USER:?Set STAGING_USER (e.g. www-data)}"
: "${STAGING_PATH:?Set STAGING_PATH (e.g. /var/www/safarakEalayna)}"
: "${DB_HOST:=127.0.0.1}"
: "${DB_PORT:=3306}"
: "${DB_USERNAME:?Set DB_USERNAME}"
: "${DB_PASSWORD:?Set DB_PASSWORD (or use ~/.my.cnf)}"
: "${DB_AUDIT_NAME:=safarak_flight_audit}"

LOCAL_TEST_DIR="tests/Feature/Flight"
REMOTE_TEST_DIR="$STAGING_PATH/tests/Feature/Flight"
TS=$(date +%Y%m%d_%H%M%S)
LOG="/tmp/flight_audit_${TS}.log"

echo "==> [1/5] Creating isolated audit DB: $DB_AUDIT_NAME"
ssh "$STAGING_USER@$STAGING_HOST" "mysql -h $DB_HOST -P $DB_PORT -u $DB_USERNAME -p'$DB_PASSWORD' -e \
  \"CREATE DATABASE IF NOT EXISTS $DB_AUDIT_NAME CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;\""

echo "==> [2/5] Uploading test files to $STAGING_USER@$STAGING_HOST"
scp "$LOCAL_TEST_DIR/FlightFullOperationsAuditTest.php" "$STAGING_USER@$STAGING_HOST:$REMOTE_TEST_DIR/"
scp -r "$LOCAL_TEST_DIR/Support" "$STAGING_USER@$STAGING_HOST:$REMOTE_TEST_DIR/"
scp "phpunit.audit.xml" "$STAGING_USER@$STAGING_HOST:$STAGING_PATH/"

echo "==> [3/5] Running migrations on $DB_AUDIT_NAME"
ssh "$STAGING_USER@$STAGING_HOST" "cd $STAGING_PATH && \
  DB_DATABASE=$DB_AUDIT_NAME DB_CONNECTION=mysql_audit php artisan migrate --force 2>&1" | tee -a "$LOG"

echo "==> [4/5] Running PHPUnit audit"
ssh "$STAGING_USER@$STAGING_HOST" "cd $STAGING_PATH && \
  DB_DATABASE=$DB_AUDIT_NAME DB_CONNECTION=mysql_audit \
  php artisan test --configuration=phpunit.audit.xml \
  --filter=FlightFullOperationsAuditTest --stop-on-failure 2>&1" | tee "$LOG"

echo ""
echo "==> [5/5] Audit complete"
echo "    Output saved to: $LOG"
echo "    View with:       cat $LOG"
echo ""
echo "    DB '$DB_AUDIT_NAME' is now populated. Inspect with:"
echo "    mysql -u $DB_USERNAME -p $DB_AUDIT_name -e 'SELECT COUNT(*) FROM flight_bookings;'"
echo ""
echo "    To clean up: bash scripts/audit_flight_cleanup.sh"
```

### `scripts/audit_flight_cleanup.sh`
```bash
#!/usr/bin/env bash
set -euo pipefail
: "${STAGING_HOST:?}"; : "${STAGING_USER:?}"; : "${STAGING_PATH:?}"
: "${DB_USERNAME:?}"; : "${DB_PASSWORD:?}"; : "${DB_AUDIT_NAME:=safarak_flight_audit}"

read -p "Drop database $DB_AUDIT_NAME on $STAGING_HOST? [y/N] " -n 1 -r
echo
[[ $REPLY =~ ^[Yy]$ ]] || exit 1

ssh "$STAGING_USER@$STAGING_HOST" "mysql -h 127.0.0.1 -u $DB_USERNAME -p'$DB_PASSWORD' -e \
  \"DROP DATABASE IF EXISTS $DB_AUDIT_NAME;\""
echo "==> DB '$DB_AUDIT_NAME' dropped."
```
