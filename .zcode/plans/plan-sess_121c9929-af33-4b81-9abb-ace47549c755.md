## Fix Plan: Notification Details Modal Not Visible

### Problem
When a user clicks a notification in the bell dropdown, the page-darkening overlay appears but the modal card with passenger details (name, PNR, route, dates) is not visible.

### Root Causes Identified
1. **Visual blending**: Modal `background: var(--surf)` (`#0E1525`) is nearly identical to the dimmed overlay color (overlay `rgba(2,8,16,.75)` over page `#080D18` ≈ `#040912`). With a 20% gold border and dark-on-dark shadow, the modal card visually merges with the page darkening.
2. **Stacking context**: The `<Teleport to="body">` is declared as a child of `.tb-end` inside `.top-bar`, which has `backdrop-filter: blur(18px)` — this creates a stacking context that may interfere with the teleported fixed-position overlay.
3. **Redundant `<template>` fragment**: A bare `<template>` wraps the three modal sections (header/body/footer), adding unnecessary indirection.

### Fix Scope
**Single file**: `resources/js/layouts/DashboardLayout.vue`

### Changes

#### Change 1: Move `<Teleport>` outside `.top-bar`
- **Cut**: The entire `<Teleport to="body">…</Teleport>` block (current lines 430–502, inside `.tb-end`)
- **Paste**: Immediately after the closing `</header>` tag (around line 508), still inside `.main-wrap` but outside `.top-bar`'s `backdrop-filter` stacking context
- This ensures the teleported overlay cannot be affected by the top-bar's stacking context

#### Change 2: Remove the `<template>` fragment
Inside the modal markup, replace:
```html
<template>
  <div class="notif-detail-header">…</div>
  <div class="notif-detail-body">…</div>
  <div class="notif-detail-footer">…</div>
</template>
```
With three direct siblings inside `.notif-detail-modal`:
```html
<div class="notif-detail-header">…</div>
<div class="notif-detail-body">…</div>
<div class="notif-detail-footer">…</div>
```

#### Change 3: Strengthen modal visual contrast
In the existing `.notif-detail-modal` rule (around line 1744), update:
- Add `position: relative; z-index: 1;` — guarantees the modal sits above the overlay background
- Border: `rgba(212, 168, 67, .2)` → `rgba(212, 168, 67, .35)` (more visible gold accent)
- Box-shadow: `0 24px 64px rgba(0, 0, 0, .6)` → `0 32px 80px rgba(0, 0, 0, .75)` (deeper drop shadow for clearer separation)
